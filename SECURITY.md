# Security

This repository is the development workspace for the takwerx ATAK plugins. Each
plugin is published from its own repository, and a report about one plugin is
best made there.

## Reporting a vulnerability

Please report it privately: open the **Security** tab of this repository, or of
the plugin's own repository, and choose **Report a vulnerability**
([this repository](https://github.com/takwerx/atak-plugins/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest release of each plugin gets security fixes.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

The plugins' code, the build and publishing scripts in this repository, and the
data the plugins download. Vulnerabilities in ATAK itself belong with the TAK
Product Center at tak.gov.
