# Security

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose
**Report a vulnerability**
([direct link](https://github.com/takwerx/evac-zone/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest release of Evac Zone gets security fixes. Update from the
TAKwerx Market or this repository's Releases before reporting.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

Evac Zone runs inside ATAK, so a flaw in it runs with ATAK's permissions on
the device. Reports about the plugin's own code, the data it downloads, and
anything it stores on the device are in scope. Vulnerabilities in ATAK itself
belong with the TAK Product Center at tak.gov.
